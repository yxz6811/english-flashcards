# Quickstart: 期末英语闪卡复习 Web 应用

## 目标

快速验证该功能的核心闭环是否可用：导入词表、闪卡学习、生词流转、撤销回滚、庆祝反馈与热力图记录。

## 前置条件

- 已具备可运行的 Web 应用基础工程
- 已准备 20 条英语词汇测试数据（图片版与文本版各一份）
- 测试环境可模拟在线与离线网络状态
- 已配置 `.env.local`（可由 `.env.example` 复制），至少配置一种 OCR 与一种 LLM 凭证

## 验证场景 A：导入到学习闭环（MVP）

1. 进入首页，选择图片导入词表。
2. 在预览列表中删除 2 条无效词并确认生成词书。
3. 进入学习页，连续完成 10 张卡片判定（认识/不认识混合）。
4. 任意一次判定后执行撤销，确认状态恢复并可重判。

**预期结果**
- 导入成功且词书词条数正确
- 学习流程连续、无卡死、无重复计分
- 撤销后状态回滚准确

## 验证场景 B：生词本 2 次掌握规则

1. 选择一个词条，先标记“不认识”使其进入生词本。
2. 连续两次标记“认识”。
3. 再对另一个词条执行“认识一次后答错一次”。

**预期结果**
- 第一词条从 0/2 -> 1/2 -> 2/2 并移出生词本
- 第二词条进度回到 0/2

## 验证场景 C：游戏化反馈与看板

1. 完成当日学习任务直至清空。
2. 观察局部庆祝（攻克单词）与全局庆祝（当日完成）。
3. 返回首页查看热力图与打卡状态。

**预期结果**
- 两类反馈均按触发条件出现
- 热力图颜色/打卡状态与当日学习量一致

## 验证场景 D：中文界面与一致性

1. 浏览首页、学习页、生词页、设置页。
2. 检查按钮、提示、空状态、错误信息文案。

**预期结果**
- 用户可见文案默认中文
- 特殊术语保留合理且风格一致

## 验证场景 E：离线可用性

1. 在线导入词书并完成一次学习。
2. 切换离线状态，继续学习并修改设置。
3. 恢复网络，刷新后检查进度与设置。

**预期结果**
- 离线可继续学习已导入词书
- 进度与设置不丢失，恢复联网后状态一致
